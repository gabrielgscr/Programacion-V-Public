# Tarea corta 3 – Investigación React Native

## Objetivo

Comprender los fundamentos de **React Native** como herramienta de desarrollo móvil híbrida y poner en práctica el consumo de servicios REST a través de una aplicación funcional de demostración.

## Tareas por realizar

Los estudiantes deberán realizar una investigación en sus grupos de trabajo sobre React Native, considerando los siguientes puntos:

### 1. ¿Qué es React Native?

- Historia y evolución.
- Diferencias entre React Native y otros frameworks móviles, como Flutter, Xamarin, entre otros.
- Ventajas y desventajas del desarrollo con React Native.

### 2. Arquitectura y componentes

- Estructura básica de una aplicación en React Native.
- Principales componentes.
- Hooks esenciales:
  - `useState`
  - `useEffect`

### 3. Consumo de APIs REST

- Uso de `fetch()` o `axios` para llamadas HTTP.
- Manejo de respuestas JSON.
- Renderizado de información en pantalla.

### 4. Desarrollo práctico

Desarrollar una pequeña aplicación en React Native que:

- Consuma datos desde una API pública REST. También puede utilizarse la API creada para el curso.
- Muestre la información en una lista con los datos obtenidos del API.

## Requisitos técnicos

- Utilizar **Expo** para facilitar la creación y ejecución del proyecto.
- Presentar código limpio, comentado y funcional.
- Crear un repositorio en **GitHub** con instrucciones de ejecución en el archivo `README`.
- Incluir capturas de pantalla del resultado final o una demo grabada.
- No es necesario incluir el código fuente dentro de la entrega.
